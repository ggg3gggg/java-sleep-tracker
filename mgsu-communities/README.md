# 🎓 Платформа землячеств НИУ МГСУ

Веб-платформа для объединения студентов НИУ МГСУ по национальным землячествам.

## 🎯 Описание

Проект создан для помощи первокурсникам и всем студентам МГСУ в поиске своих земляков и вступлении в землячества. Каждое землячество имеет уникальный культурный дизайн, отражающий традиции и атрибутику народа.

## ✨ Возможности

- 📋 Каталог кавказских землячеств (9 землячеств)
- 🎨 Уникальный дизайн для каждого землячества
- 🔍 Поиск землячеств
- 📝 Форма вступления в землячество
- 📱 Адаптивный дизайн для мобильных устройств
- 💬 Прямая связь с председателями через Telegram
- 📚 Раздел для первокурсников с FAQ
- ℹ️ Информация о проекте и контакты

## 🌍 Землячества

1. Чеченское
2. Ингушское
3. Дагестанское
4. Карачаево-Черкесское (КЧР)
5. Кабардино-Балкарское (КБР)
6. Грузинское
7. Армянское
8. Азербайджанское
9. Осетинское

## 🚀 Запуск проекта

### Локально

Открыть `index.html` в браузере или запустить локальный сервер:

```bash
# Python 3
python3 -m http.server 8000

# Затем открыть http://localhost:8000
```

### GitHub Pages

Проект готов к деплою на GitHub Pages:

1. Запушить код на GitHub
2. В настройках репозитория включить GitHub Pages
3. Выбрать ветку и папку (main / root)

## 🎨 Особенности дизайна

Каждое землячество имеет:
- Уникальные цвета (на основе флага)
- Национальные орнаменты и паттерны
- Культурную атрибутику
- Узнаваемую визуальную идентичность

## 💡 Как вступить в землячество

1. Выбрать свое землячество в каталоге
2. Нажать "Вступить"
3. Заполнить короткую заявку
4. Отправить сообщение председателю в Telegram
5. Дождаться ответа (обычно в течение 24 часов)
